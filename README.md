# Predictive-Analytics Module

This repo contains the labs and assessments I have done from the modele Predictive Analytics @ ATU. 

# Module Learning Outcomes
1. Identify and evaluate logistic regression models and their suitability for an
assigned use case.
2. Design a time series forecast model using previously identified datasets aligned with an assigned use case.
3. Develop and document the procedures required to build a time series model.
4. Plan and implement a timeseries model and evaluate itseffectiveness and fit throughrelevant metrics.
5. Develop and present dataforecasts using appropriatevisualisation tools.
